# Hunt’s Property Services website

This is a responsive static website for Hunt’s Property Services.

## Before publishing
1. Replace `YOUR_FORMSPREE_ID` in `index.html` with your Formspree form ID.
2. Replace `YOUR_FACEBOOK_LINK` and `YOUR_GOOGLE_BUSINESS_LINK` in `index.html` with the real links.
3. Upload the whole folder to GitHub Pages (or another static host).
4. Connect your custom domain.

The message form is designed for Formspree. Formspree provides the form endpoint after you create a form in its dashboard.
